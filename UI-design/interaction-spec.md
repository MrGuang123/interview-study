# 页面与交互实施规范

日期：2026-10-22。状态：**静态设计与实施约定，尚未接入真实 API 或完成交互验收**。图片索引见 [README](README.md)，设计值以 [tokens.json](../packages/design-tokens/src/tokens.json) 为准。本文补充图片难以完整表达的状态、归属和手机行为，不把图稿变成已实现能力清单。

## 1. 范围与通用规则

首条链路为登录 → 题库 → 新建私人练习 → 编辑 → 手动保存 → 我的练习 → 继续，先使用纯文本输入。自动保存、富文本、正式提交、复盘报告、离线草稿和 AI 按后续阶段实施。全站页面稿表达长期方向，不表示每页全部按钮都进入首批开发。实施范围以 [首条链路清单](../docs/stage-2-first-slice.md) 为准。

页面路由以 [manifest.json](manifest.json) 为索引；复盘、房间详情、账号设置和内容编辑的详情路径标注为建议。图片中的附加菜单、小字、次级标签或模型自动补出的入口，不构成新的正式路由、角色、业务能力或认证方式。

- 公共信息与私人数据分开获取。私人响应、编辑内容与缓存按当前账号/工作空间隔离；切号后不能残留上一账号的内容。
- 读取中保留布局，不显示虚假的成功内容；已有旧结果可保留，但标明上次结果，不能冒充最新数据。读取失败给出可理解的提示和重试入口。
- 区分“题库确实为空”与“筛选后无结果”：前者说明尚无已发布内容，后者提供清除筛选。不能用同一个按钮假装能解决所有空状态。
- 按钮、状态图标与文案一起表达结果，不只依赖红绿颜色。服务端返回之前不显示保存、发送、发布或撤销成功。
- 键盘焦点可见；对话框进入后焦点留在对话框，关闭后回到触发位置。输入标签保持可见，错误关联对应字段，按钮不靠图标猜含义。
- 浅深色使用同名语义，跟随系统是初版方向；设置页的手动选择是配套设计。减少动效时直接切换状态，保留文字进度与操作能力。
- H5 使用内容重新排序、单列、标签页和抽屉；至少按 320、390 的参考宽度与文字放大验收。页面高度可增长，按钮交互目标至少 44，底部操作区考虑键盘与设备安全区域。

## 2. 首条链路的编辑与保存语义

### 2.1 本地编辑和服务端快照分开

编辑区显示的是当前用户正在输入的文本；最后成功读取/保存的内容与版本是另一份快照。后台重新读取、列表缓存刷新或旧请求返回，都不能直接覆盖有未保存改动的编辑区。

| 状态 | 进入条件 | 文案与行为 |
| --- | --- | --- |
| 未修改 | 当前文本等于已读取的服务端快照 | 提示“尚未修改”；保存按钮不发重复写入 |
| 未保存 | 当前文本与最近确认快照不同 | 提示“未保存”；允许手动保存 |
| 保存中 | 已发送一份固定文本快照，尚未得到结果 | 提示“正在保存”；保持文本可见；允许继续输入，单次写入未结束前不并发发送另一份新快照 |
| 已保存 | 服务端确认的快照恰好等于当前文本 | 显示“已保存”及服务端确认时间；不使用设备时间伪造保存时间 |
| 新改动未保存 | 旧快照得到确认，但用户随后输入了不同文本 | 显示“新改动未保存”；更新已确认版本，保留新文本并允许再次保存 |
| 保存失败 | 超时、连接错误或服务端受控失败 | 保留文本，提示“保存失败，文字已保留”，给出重试；响应丢失时不能断言服务端完全未写入 |
| 身份失效 | 保存或受保护读取返回 401 | 停止自动重试写入，保留当前页文本，进入重新登录流程 |
| 版本冲突 | 新保存使用的基础版本已旧，返回 409 | 保留本地文本，展示云端版本比较，用户人工处理后再保存 |

只保留内存文本不等于本地草稿功能；刷新、关闭浏览器或页面销毁后不保证恢复。首版不在 UI 上承诺自动保存、离线保存或刷新恢复未提交的文字。

### 2.2 保存中继续输入

示例：页面读取服务端 `v3 = A`；用户编辑成 `B`，发送快照 `S1 = B`，基础版本为 v3；请求进行时又输入成 `C`。服务端返回 `S1` 保存成功及 v4 后：

1. 最近确认快照更新为 B，基础版本更新为 v4。
2. 编辑区继续显示 C，光标与选区不跳回 B。
3. 当前状态为“新改动未保存”，不能显示整份 C 已保存。
4. 下一次保存发送 C，使用新操作标识与基础版本 v4。

同一次快照的重试复用原操作标识与原文本；用户产生新内容并明确再次保存，则生成新操作标识。超时后先重试/核对原操作结果，不能把另一份内容塞进同一个操作 ID。响应还应匹配当前账号、练习和请求，避免已离开的页面或旧账号结果更新当前界面。

[保存状态板](states/save-and-conflict-light.png) 的第 04 格把请求中与确认后两个时刻并列说明；实现时按上述先后切换，不同时显示互斥的“正在保存 S1 / S1 已保存”。

### 2.3 401：重新登录前保住当前页输入

401 不是保存成功，也不是删除编辑内容的理由。关闭保存中的忙碌状态，展示身份失效提示；原文本暂留当前页面，明确“请勿刷新或关闭：仅本页暂留”。

首版优先使用**页内重新登录对话框**完成鉴权：按钮“重新登录并返回”在对话框内登录成功后回到原练习编辑区与原文本，而不是先卸载编辑页再期待内存仍存在。若以后采用独立登录页跳转，必须先设计并实现账号隔离的恢复机制；在此之前不承诺跨页面导航后能恢复输入。

重新登录需确认仍是原账号，随后重新校验对象权限与当前服务端版本；版本变化时走冲突比较，不能自动重放旧写入。登录成另一个账号时，旧账号内容不得展示给新账号或作为新账号写入；切号流程需处理未保存内容并清理旧账号缓存。恢复目标仅允许应用内受控路径，不能信任任意外部返回地址。

### 2.4 409：人工比较和合并

冲突示例以 `base v3` 与 `server v4` 表示本地开始编辑时的版本和当前云端版本，时间戳仅作说明，不用于决定谁覆盖谁。

1. 保留本地完整文本和其基础版本，读取当前有权访问的云端文本与版本；读取失败时仍保留本地内容。
2. 展示“本地 · base v3 / 云端 · server v4”，可比较差异，说明不会自动覆盖任一版本。
3. 用户选择“比较后手动合并”，在可编辑区域形成合并后的文本；提供继续保留本地内容的退出路径，不能自动采用云端替换正在编辑的文本。
4. 用户确认合并后，用 v4 作为基础版本和新操作标识发起保存。期间云端又变化则再次提示冲突，不能退化为强制覆盖。
5. 若以后提供“采用云端版本”，须先明确说明会放弃哪些本地改动，并由用户主动选择；不能把读取云端当作自动同意丢弃本地输入。

首版不承诺 CRDT、自动三方合并或所有内容无冲突同步。

### 2.5 离开、刷新和切号

应用内返回、切换练习、退出账号或切号前发现未保存文本时，弹出“还有未保存的内容”，提供“继续编辑”和“放弃并离开”。继续编辑关闭对话框并回到原焦点；放弃必须由用户明确选择。若另提供先保存再离开，只有相应快照得到服务端确认、且之后没有新输入时才完成离开。

浏览器刷新/关闭可按浏览器支持使用原生离开提示，不能保证拦住所有页面终止。提示不会使内存内容持久化；未来离线草稿需另行实现、标明恢复范围并按账号隔离。

## 3. 17 类页面的用户流程

### 01 登录 `/login` · 首条链路

- **入口**：未登录访问受保护页面；会话过期后页内重新登录；公共页上的登录入口。
- **主要操作**：输入登录标识和密码，提交，读取当前身份后进入受控返回路径。首批无返回目标时进入题库/我的练习等已实现入口；不跳入尚未实现的工作台。
- **关键异常**：字段格式错误在字段旁说明；凭据不匹配给出统一错误，提交中避免重复操作；网络失败可重试。重新登录按 2.3 保留当前页文本。图片不能引入未经确定的注册、短信或第三方登录方式。
- **手机改版**：单列表单，字段标签常显，按钮全宽或易触达；键盘弹出后可滚动至提交按钮，不能把输入和错误挤出视口。

### 02 学习工作台 `/app` · 后续阶段

- **入口**：登录后导航“工作台”；首批尚未实现时不作为默认成功目标。
- **主要操作**：查看今日复习、最近回答、当前工程任务、下一场面试，从具体卡片进入相应业务；各区独立加载。
- **关键异常**：某区读取失败仅影响该区，显示本区重试；没有任务显示实际可用的开始入口。最近活动不是已保存证据，时间和状态来自所属服务。示例图表不能冒充真实学习效果。
- **手机改版**：优先展示今日行动和最近练习，统计卡纵向或两列，次要区折叠；核心导航不因内容滚动消失到无法返回。

### 03 题库 `/questions` · 首条链路

- **入口**：公共题库入口、导航“题库”、我的练习空状态。
- **主要操作**：阅读题名与分类/摘要，分页；已实现筛选时把条件写入 URL，搜索/标签属于设计范围但不强制塞进最小首版。新练习经确认的题目版本创建私人练习；“继续练习”指向明确已有练习，不偷偷新建一份。
- **关键异常**：加载骨架、真实空库、筛选无结果、读取失败分开表达。开始练习未登录时鉴权；创建中避免重复发起，失败重试复用同一操作标识，不能产生多份意外练习。第一版公开详情尚未上线时，可由列表直接进入开始练习流程。
- **手机改版**：题目纵向卡片，分类/筛选折入抽屉或可换行区域；开始/继续按钮不覆盖题名，分页控件可触摸，搜索不要求横向滚动。

### 04 题目详情 `/questions/[slug]` · 后续阶段

- **入口**：题库题名、关联知识、工作台任务中的题目链接。
- **主要操作**：阅读题干、资料、关联知识与发布版本；查看自己有权访问的历史回答；根据当前选定版本开始新练习。
- **关键异常**：题目不存在、未发布或无权访问时展示受控不可用状态；个人历史失败不阻断公共题干。题目新版发布不改写历史练习引用的旧版本；资料不可用时标明来源问题，不编造引用。
- **手机改版**：题干优先，资料/历史切换为分区或折叠；主要练习动作放在不遮挡正文的操作区，长代码独立横向滚动。

### 05 我的练习 `/app/practice` · 首条链路

- **入口**：导航“我的练习”、保存后返回、重新登录后的继续入口。
- **主要操作**：列出自己的题目、最近服务端保存时间、练习状态，分页并继续明确的练习 ID。首批只展示真实具备的草稿状态；提交/报告状态随后续能力启用。
- **关键异常**：空列表提供去题库入口；加载失败提供重试；401 进入登录；无权对象按既定契约处理，不能展示他人练习。界面中的本地“未保存”状态不冒充跨设备可见的云端保存时间。
- **手机改版**：桌面紧凑行转单列卡片，题目与保存时间在上、继续动作在下；长题名允许换行，不挤掉状态。

### 06 答题工作区 `/app/practice/[attemptId]` · 首条链路

- **入口**：题库创建成功、我的练习继续、受控练习链接。
- **主要操作**：读取练习引用的题目版本与云端草稿，纯文本编辑，手动保存，返回列表。提纲与自测属于设计扩展；图中富文本工具不意味着首版安装富文本编辑器。
- **关键异常**：严格按第 2 节区分未修改、未保存、保存中、已保存、保存失败、401、409和离开确认。读取失败不显示空白编辑器冒充新草稿；无权或不存在不给私人内容。后台 refetch 不覆盖未保存文本。
- **手机改版**：题干与编辑区改纵向或明确标签切换，侧提纲收进抽屉；保存状态始终可见，键盘打开后主要操作可达，不能把全部桌面栏挤在一屏。

### 07 复盘与报告 `/app/practice/[attemptId]/review` · 后续阶段，路由建议

- **入口**：后续的明确提交动作、我的练习中已提交记录、报告通知。
- **主要操作**：查看不可变提交、自评/互评维度、报告与依据，安排复习。重新作答形成新的草稿/练习，不修改旧提交快照。
- **关键异常**：报告待处理、生成中、失败、完成分开；报告失败仍可读已提交答案。权限失效不可读取他评私有资料；评分为可解释的学习反馈，不显示未经测量的确定性进步结论。
- **手机改版**：先展示结果摘要与下一步，分项和证据可展开；对比内容分段切换，不保留细小双栏，图表配文字解释。

### 08 模拟面试大厅 `/app/rooms` · 后续阶段

- **入口**：导航“面试房间”、工作台下一场面试、小组邀请。
- **主要操作**：查看预约、创建/加入有权访问的场次、邀请成员，设置时段、场次角色和题集；角色只作用于指定场次。
- **关键异常**：过期邀请、房间已结束、无权限、时段冲突和创建失败有明确状态；加入/邀请重复请求去重。不能从“面试官”角色获得对方全站私人资料，也不把文字房间设计扩成已具备音视频。
- **手机改版**：场次列表转卡片，时间/状态清晰，创建表单分段，邀请信息在确认前完整可见。

### 09 模拟面试房间 `/app/rooms/[roomId]` · 后续阶段，详情路由建议

- **入口**：大厅的加入动作、有效邀请、已确认的当前场次。
- **主要操作**：查看参与者、共同题目、服务端计时，发送文字消息，按权限和编辑锁修改画布；计时以服务端状态校正，设备时钟不作为最终事实。
- **关键异常**：消息区分待确认、服务端持久化后已确认、发送失败；超时不删除输入，以同一消息/操作 ID 重试避免重复。断线后重新鉴权并从持久状态补齐，不能把 Socket 重连等同全部消息已恢复。画布展示当前锁持有人、锁过期或版本冲突；写入需服务端复核，丢锁后暂停写入并保留未提交内容。首版编辑锁不冒充多人同时编辑。
- **手机改版**：题目、聊天、画布使用标签切换，共享计时与连接状态保持紧凑可见；画布有可用的简图/列表路径，消息输入不被底部导航或键盘遮挡。

### 10 系统设计实验室 `/app/lab` · 后续阶段

- **入口**：导航“实验室”、工程任务、已授权场景/版本。
- **主要操作**：放置/连接节点、选择并修改参数、撤销重做、保存场景版本、比较方案和回放。2D/3D共享稳定场景模型，显示输入假设、随机种子与模拟条件。
- **关键异常**：非法连接、参数越界、保存冲突、计算失败、低性能或图形上下文丢失均有受控反馈；保留场景模型并提供2D/列表回退。实验曲线与动画只代表模型假设，不证明平台真实吞吐量或恢复时间。
- **手机改版**：画布为主，节点库和属性变为抽屉，时间线可折叠；可用简图/列表和表单操作，不要求手机操作完整三栏桌面或持续3D动画。

### 11 小组与共享计划 `/app/groups` · 后续阶段

- **入口**：导航“更多”内小组、邀请、工作台共享任务。
- **主要操作**：切换有权加入的小组，查看成员与角色、共享计划、互评、设计版本和工程证据；编辑/管理动作按当前小组权限显示。
- **关键异常**：邀请过期、成员被移除、权限变化、计划冲突或任务已处理时刷新状态并说明，服务端再次校验。切组清理或重新绑定旧上下文，不能把上一小组的私人内容带入当前组；互评只暴露被授权的对象。
- **手机改版**：小组切换器置顶，计划/成员/互评分段，成员表转列表卡片；角色变更前显示对象与影响，长列表可分页。

### 12 项目档案 `/portfolio/[slug]` · 后续阶段

- **入口**：用户公开的作品链接、分享链接、本人预览。
- **主要操作**：阅读用户明确选定的成果、英文说明、版本证据和演示，按授权提供分享/导出。本人预览清楚区分“仅自己可见”和实际公开内容。
- **关键异常**：未公开、撤回、过期或不可访问的分享显示受控状态。不能因拥有公开 slug 就读取私人回答、聊天、错误日志、密钥或完整内部运行数据；公开接口和导出都应限定到已选择的内容。分享/导出不自动扩大原权限。
- **手机改版**：公共页使用合适的公开头部，成果按阅读顺序纵向展示；长英文/代码可读，证据附件有明确名称，不能塞入后台侧栏。

### 13 离线与同步 `/app/offline` · 后续阶段

- **入口**：导航“更多”中的离线中心、网络状态提示、明确的题包下载动作。
- **主要操作**：主动下载有版本题包，查看本地草稿、待同步操作、同步中、冲突与失败；联网后先重新鉴权、检查当前权限及版本，再同步。
- **关键异常**：空间不足、存储被清理、下载中断、格式不兼容、会话失效或同步冲突明确提示，保留可恢复内容并提供导出路径。离线队列按账号/工作空间隔离，不向当前其他账号重放；不能因网络恢复就跳过权限。冲突走人工比较，不按设备时间覆盖。升级需处理旧题包与旧草稿，不能承诺加插件即自动兼容。
- **手机改版**：题包和草稿单列，下载大小/版本/状态清晰；操作菜单适合触摸，底部同步提示不盖住列表，离线时仍能进入明确的离线入口。

### 14 AI 学习教练 `/app/coach` · 后续阶段

- **入口**：独立教练页、工作台/练习上下文中的明确入口。
- **主要操作**：流式对话、追问、复盘，查看有权访问的引用与工具摘要；修改计划前展示当前值/建议值差异、作用范围与确认动作。用户确认后才交由所属业务服务复核权限、版本并幂等执行。
- **关键异常**：断流、模型失败、预算限制、引用失效、工具拒绝或版本变化说明当前已完成/未完成部分，不伪装成功。取消分为请求取消、取消中、已取消/已完成：停止新步骤，保留已显示内容和工具结果；已完成的写入不能因为关闭对话或取消流而假称撤销。待确认方案取消后不执行；确认与写入并发时最终以实际业务回执为准。AI 不可用仍可正常作答、自评与复习。
- **手机改版**：会话列表收进抽屉，聊天单列、输入框随键盘可达；引用与工具摘要可展开，计划差异在确认前完整可读，取消按钮持续可达。

### 15 管理与运行中心 `/ops` · 后续阶段

- **入口**：经授权维护者的运维入口或受控链接；前端隐藏入口不替代服务端鉴权。
- **主要操作**：查看失败任务、错误聚合、追踪、发布与备份/恢复演练记录，必要时跳到已有运维工具。图中“查看恢复演练”只读取记录；实际恢复必须走独立受控运维流程，不设计为随手覆盖在线数据库的普通按钮。
- **关键异常**：指标延迟标明采集时间，读取失败保留受控旧结果；无权限、记录不可用与工具链失败明确反馈。后续如增加任务重试，需显示对象、效果和幂等约束并复核权限；不能把所有失败统一无限重试。敏感内容脱敏，不展示凭据、完整私人回答或未授权模型上下文。
- **手机改版**：优先状态摘要与失败任务卡片，详情用抽屉/单页；追踪字段可复制，表格可进入有标签的横向滚动区域，受控运维操作不能因窄屏省略影响说明。

### 16 账号与设备 `/app/settings` · 配套设计，路由建议

- **入口**：头像/设置菜单、身份失效或设备管理提示。
- **主要操作**：查看基本身份资料与独立设备会话，区分当前设备，撤销指定会话；主题与减少动效偏好作为后续控件设计，初版主题仍跟随系统。
- **关键异常**：设备已撤销、会话过期或资料保存失败时重新读取并说明；撤销当前设备需明确将退出本次会话，处理未保存内容后执行。撤销一个设备不等于注销全部设备。重新登录或切号遵守账号隔离。
- **手机改版**：资料和设备转单列，设备名称允许换行；危险操作独立分组，确认中显示具体设备与当前会话影响，不能只显示模糊的删除图标。

### 17 题目编辑与发布 `/ops/questions/[questionId]/edit` · 配套设计，路由建议

- **入口**：有内容维护权限的题库管理入口、题目版本列表；不从普通学习者导航进入。
- **主要操作**：编辑草稿、预览、检查题干与资料、比较版本差异，校验通过后明确确认发布；历史发布版本保留，既有练习继续指向原题目版本。
- **关键异常**：输入非法、权限变化、草稿保存失败、并发冲突或发布验证失败时保留编辑并说明。发布中不重复创建版本，确认后以服务端回执为准；发布新版不能悄悄覆盖旧提交引用。支持的内容格式与安全渲染需随实际编辑器选型验证，图中的工具栏不是已确定的编辑器方案。
- **手机改版**：编辑/预览/版本比较分段切换，字段纵向排列；发布操作可触达但必须先读到校验问题与版本影响，未保存离开遵守确认规则。

## 4. 设计转实现的验收边界

第一轮真实浏览器验收先覆盖四页：登录、开始/继续、输入、保存、刷新读取、重新登录、第二设备读取、其他账号隔离，以及加载/空/失败/401/409/离开。保存只证明云端草稿被确认，不能等同提交、评分、报告或备份恢复。

后续页面在对应业务阶段另做有权限、失败和恢复的可交互验证。房间消息确认必须有持久依据，离线重放必须重新鉴权，AI写入必须对应确认与业务回执，恢复演练必须记录受控环境与实际结果。图片里的示例数值、已完成标记和成功提示，都不能作为这些能力通过验收的证据。

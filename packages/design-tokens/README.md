# design-tokens：统一设计规范

状态：已预留职责目录，未创建令牌文件、生成器或主题实现。

## 负责

维护平台中立的语义化颜色、字号、间距、圆角、层级与组件状态规范，再映射到各运行环境。令牌源采用 JSON 或 TypeScript 等中立表达，不能只存在于 Tailwind 配置中。

候选结构：`src/tokens/` 放源定义，`src/platforms/web/` 放 Web 映射；未来确有原生/小程序客户端时再增加对应输出。生成文件应标记来源并能重复生成。

## 边界与验收

- Web 将令牌映射为 CSS 变量/Tailwind 主题；shadcn 组件当前留在 `apps/web`。
- 不在此包存放 React DOM、React Native、小程序组件或业务页面。
- 统一设计语言不等于所有端逐像素相同；字体缩放、键盘、触摸和安全区域仍由平台处理。
- 首次启用先验证 Web 明暗主题、焦点、禁用和错误状态；第二个平台出现后再验证相同语义令牌的映射，不提前声称全端一致。

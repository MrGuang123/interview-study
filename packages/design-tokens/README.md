# design-tokens：统一设计规范

状态（2026-10-22）：已创建平台中立源 [`src/tokens.json`](src/tokens.json)，覆盖整站浅深色渐变设计。尚无包清单、生成器、Web CSS 输出或应用集成；创建令牌不表示业务页面已实现。页面概念图与目录见 [`UI-design`](../../UI-design/README.md)。

## 设计范围与边界

令牌以用户认可的浅深色 UI v0 为基础：专业工具布局，蓝紫主操作，页面低强度渐变柔光。题干、编辑器、输入、表格和聊天内容使用纯色表面，避免柔光影响长时间阅读。图稿表达视觉方向，图片生成可能带来局部色差、尺寸差和文字误差；代码实施以令牌与实际页面验收为准，不能从图片逐像素反推规范。

本包只维护设计值及平台映射约定，不包含 React DOM、React Native、小程序组件或业务页面。统一语义不表示各端逐像素一致；文字缩放、键盘、安全区域和交互方式由平台处理。shadcn 组件以后仍由 `apps/web` 消费这些语义。

## 令牌结构

| 分组 | 内容 |
| --- | --- |
| `meta` | 版本、单位、引用方式、适用表面与配色规则 |
| `colors.light / dark` | 两种主题各 44 个同名语义色：表面、文字、控件边界、主操作、选中、链接、焦点、状态、图表等 |
| `fontFamily / fontSize / lineHeight / fontWeight / letterSpacing` | 系统中英文字体、代码字体、字号、行高、字重和字距 |
| `spacing / radius / size / borderWidth` | 间距、圆角、图标/头像/控件尺寸、边框 |
| `layout` | 桌面与 H5 外壳、阅读宽度、登录、实验室、房间、教练、档案和运维布局 |
| `gradient.light / dark` | 主按钮线性渐变及三组低透明度背景径向柔光，保留角度、位置、颜色引用与透明度 |
| `shadow.light / dark` | 面板、浮层、对话框与主操作阴影，以偏移、模糊、扩散、颜色及透明度分开存储 |
| `components` | 按钮、输入、编辑器、导航、卡片、表格、聊天、节点、弹窗、抽屉、提示等尺寸和配色绑定 |
| `duration / easing / motion` | 150—180ms 微交互、260ms 面板过渡、贝塞尔参数、减少动效规则 |
| `breakpoints / zIndex / opacity` | Web 最小视口断点、相对层级和透明度 |
| `accessibility` | 对比度、触摸目标、文字缩放、状态反馈与减少动效约定 |

`colors.light/dark` 始终是平铺的十六进制字符串；`fontSize`、`radius`、`spacing`、`duration` 始终是平铺数值，兼容 [主题指南](../../docs/ui-theme-guide.md) 中介绍的基础生成方式。该基础生成器只处理少数组，**不会自动输出新增的渐变、阴影、组件或布局令牌**。后续集成应扩展映射能力，不能用指南中的精简示例覆盖完整源文件。

## 单位与引用

- 尺寸、间距、字号、边框和阴影几何使用无后缀数字，表示设计中的 px 等价值。Web 可将可缩放值按 `value / 16` 输出为 `rem`，断点按 CSS 视口 px 输出；其他平台转为自己的逻辑单位。
- 字号、行高、字重分开存储。`lineHeight.body: 1.6` 为倍率，不是 px；`letterSpacing` 为 em；`duration` 为 ms；角度为度；透明度与渐变色标位置在 0—1 之间。阴影扩散可以是负值。
- `{"$ref":"#/radius/control"}` 是指向本文件的绝对 JSON Pointer 别名，解析为数值 `8`。映射器应递归解析，并拒绝循环或不存在的引用。它是本项目令牌协议，不是外部 JSON Schema 引用。
- `components` 中的 `colors.<mode>.surface`、`gradient.<mode>.primary` 等字符串是**平台绑定指令**，不是 `$ref` 值别名；适配器先将 `<mode>` 替换为 `light` 或 `dark`，再读取对应路径。这样结构与布局可共享，颜色随模式变化。
- 渐变显式采用 `srgb` 插值；Web 输出时保留该插值空间，不能静默改成另一种色彩空间。渐变色标与阴影颜色引用中保留独立透明度，不把 `linear-gradient(...)`、`rgba(...)` 或整段 `box-shadow` 当作唯一真相。Web 适配器负责拼成 CSS；其他平台可消费同样的结构化值。
- 径向渐变中心使用画布宽高的比例，半径是绘制区域较长边的比例；Web 输出前需据此换算尺寸。装饰渐变不承担内容或状态信息。

## 关键实施值

- 桌面侧栏 192、收窄图标栏 72、顶栏 72、内容主间距 22；阅读宽度最多 760。H5 顶栏 56、底部导航 64、页面内边距 16；安全区域用运行时数据另加。
- 正文 14、中文正文行高 1.6；段落标题 18、区块标题 22、移动页标题 24、桌面页标题 32。移动输入文字 16，允许浏览器缩放。
- 面板圆角 14、窗口 18、控件 8；标准按钮/输入最小高度 44。紧凑控件视觉高 36 时，外围交互目标仍至少 44。
- 页面按可用空间选布局：实验室画布、编辑器与聊天在窄屏改为纵向/切页，不能简单缩小桌面多列。`layout.mobile.reference-width: 390` 是设计参考，`supported-min-width: 320` 是待实现验收目标，不表示浏览器已验证。
- 高度多为最小值，文字增大或换行时允许扩展。对话框与长内容必须可滚动，不能固定高度裁掉操作。

### 配色使用规则

| 用途 | 前景 / 背景 |
| --- | --- |
| 正文、题干、编辑区 | `foreground` / `surface`（页面底色用 `background`） |
| 次级说明 | `muted-foreground` / `background` 或 `surface` |
| 次级表面的说明 | `muted-surface-foreground` / `surface-muted` 或 `surface-hover` |
| 选中项 | `selection-foreground` / `selection` |
| 主操作 | `primary-foreground` / `gradient.<mode>.primary`；悬停/按下改用对应纯色 |
| 危险操作 | `danger-foreground` / `danger`，悬停使用 `danger-hover` |
| 成功/警告/错误/信息提示 | 对应状态色 / 对应 `*-surface`，同时有文字或图标 |
| 输入边界 | `border-control`；`border` 只作面板与行的柔和分隔 |
| 键盘焦点 | `focus`，线宽 2、偏移 2，内侧留纯色间隔 |

浅色装饰紫保留 `accent-violet: #7c66e8`；它配白字仅约 4.27:1，因此可放在柔光、装饰或大形状里。普通主按钮改用 `#5263dc → #745edb`，白字达到 4.81:1；与图稿紫色只有轻微差别。深色按钮为 `#9eaafa → #baabf8`，文字 `#151a32`。

原浅色 `primary` 在 `selection` 上仅约 4.39:1，因此选中项正文使用新增的 `selection-foreground: #4958c9`。原 `muted-foreground` 不用于 `surface-muted`，改用 `muted-surface-foreground: #5f6b82`。开发时应使用正确语义组合，避免给整块组件降低透明度而改变已核对的文字对比度。

## Web / Tailwind 后续接入

1. 继续按 [主题指南](../../docs/ui-theme-guide.md) 为本包建立生成和导出，再把包以 `workspace:*` 引入 Web；本轮没有执行这些步骤。
2. 平台映射生成 `--forge-color-*`、`--forge-radius-*`、`--forge-font-size-*` 等变量。渐变、阴影、布局和组件令牌需新增相应输出；不得手改生成 CSS。
3. Web 的 `@theme inline` 显式把颜色、字号、圆角和间距变量映射到 Tailwind 语义。完成映射后页面使用 `bg-surface text-foreground rounded-panel` 等类，避免逐页写十六进制颜色。
4. 新增的选中和焦点语义也应显式映射，例如 `--color-selection-foreground: var(--forge-color-selection-foreground)`；有变量值不等于已经注册了 Tailwind 工具类。
5. 明暗模式换同名令牌。首版仍跟随系统；设置页图稿中的手动选择属于后续界面设计，不代表切换功能已实现。
6. 减少动效时去除位移/缩放，过渡直接切换；保存中、错误、进度仍用文字反馈。默认不运行背景动画和闪烁骨架。

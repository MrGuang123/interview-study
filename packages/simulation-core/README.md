# simulation-core：教学模拟模型

状态：已预留职责目录，未实现计算引擎。

## 负责

- 架构实验的节点、连接、参数、稳定 ID、格式版本与校验。
- 教学模型的计算、结果、限制和必要的确定性回放。
- 为浏览器计算 Worker 和经授权的服务端工具提供可复用算法。

候选结构：`src/model/`、`src/validation/`、`src/engine/`、`src/replay/`。计算输入/输出显式传递，采用随机模型时允许固定种子。

## 边界与验收

- 纯 TypeScript，不依赖 DOM、React、Three.js、Nest、数据库和网络身份上下文。
- Three.js 渲染、拖动与界面状态留在 Web；场景保存、版本和权限留在 studio-service。
- Web Worker 的调度、进度和取消消息在应用适配层处理，长计算支持分批执行的方式按实际需求设计。
- 明确这是教学模型，不能把结果称作真实基础设施压测数据。首次启用验证固定输入结果、边界参数与格式迁移，再接入 Worker/UI。
